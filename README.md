A launch-day shape forecaster for GTA VI's Twitch viewers. From hour 1's print it forecasts hours 2-24 of release day (2026-11-19 UTC) as five quantiles each, fitting the release-day curve from past big launches in the case's comparables: each launch weighted by how close its hour-1 print is to this case's (Gaussian kernel on log hour-1 viewers), with the spread from the cross-launch dispersion per hour. Leave-one-out validation on the comparables: mean pinball loss 0.44 vs the persistence baseline's 0.93.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
